================================================================================
⚙️ ENGINE TECHNICAL SPECIFICATIONS
================================================================================
Output Format:
Return a single, strictly valid JSON object — no markdown fences, no trailing commas, no comments.
The top-level keys must be exactly:
id, name, category, icon, version, author, description, enabled, defaultProps, schema, template, customCss, customJs.

Property Types (Inspector Controls):
--------------------------------------------------------------------------------
type           Inspector Control                       Notes
--------------------------------------------------------------------------------
text           Single-line text input                  Use for titles, labels, short strings
textarea       Multi-line text input                   Use for body copy, descriptions, CSV URLs
number         Numeric input                           Default value should be a number
toggle         On/Off switch                           Default value: true or false
color          Color picker                            Default value: hex string, e.g. "#6366f1"
select         Dropdown list                           Requires options: [{ "label": "...", "value": "..." }]
image-picker   Image URL + Media Library button        Value is a URL string. User can pick from Media Library
page-link      Page Selector + Custom URL              MANDATORY FOR ALL LINKS! Admin dropdown of created pages
                                                       plus free-text for anchors (#section) and external URLs.
                                                       Never use plain "text" for link fields.
repeater       Elementor-style repeatable list         Requires fields: [...] array. Supports infinite nesting!
--------------------------------------------------------------------------------

📦 REPEATER FIELDS & NESTED DROPDOWNS
Repeaters support nested child repeaters. To create a navigation menu with dropdown submenus:
{
  "key": "navItems",
  "label": "Navigation Links",
  "type": "repeater",
  "fields": [
    { "key": "label", "label": "Menu Label", "type": "text" },
    { "key": "link",  "label": "Page / URL",  "type": "page-link" },
    {
      "key": "children",
      "label": "Submenu (Dropdown Items)",
      "type": "repeater",
      "fields": [
        { "key": "label", "label": "Sub-item Label", "type": "text" },
        { "key": "link",  "label": "Sub-item Link",  "type": "page-link" }
      ]
    }
  ]
}

🧩 TEMPLATE ENGINE SYNTAX (Handlebars-Style)
Variables:
{{key}}           → Outputs the value of `key` from props
{{@index}}        → 0-based index inside a loop
{{@number}}       → 1-based index inside a loop (human-friendly)
this              → In a primitive array loop, outputs the value itself

Conditionals:
{{#if key}}...{{/if}}
{{#if key}}...{{else}}...{{/if}}
{{#unless key}}...{{/unless}}

Loops & Nested Loops:
{{#each navItems}}
  <li class="{{#if children}}has-dropdown{{/if}}">
    <a href="{{link}}">{{label}} {{#if children}}<span class="caret">▾</span>{{/if}}</a>
    {{#if children}}
      <ul class="submenu">
        {{#each children}}
          <li><a href="{{link}}">{{label}}</a></li>
        {{/each}}
      </ul>
    {{/if}}
  </li>
{{/each}}
Inside nested loops, parent scope variables are accessible automatically.

================================================================================
🚀 NEW ADVANCED CAPABILITIES (v2.9.46 - v2.9.54)
================================================================================

1. Multi-Source Live Sync (Google Sheets & SQL/REST API):
Add-ons can dynamically fetch live data while keeping local fallback JSON:
- Provide a select field for "sourceType" ("manual", "gsheet", "api").
- In customJs, if "gsheet" is selected, fetch CSV from Google Sheets published URL,
  parse rows, and render dynamically. If fetch fails or is offline, fall back to props.items.

2. SEO Primary Heading (<h1>) & Hero Add-on Standard:
If an add-on serves as a Hero section, Portfolio showcase, or Page Header:
- Always wrap the primary headline in an <h1> tag: <h1 class="wb-addon-title">{{title}}</h1>
- AetherBuilder's Pre-Publish SEO & Health Pre-Flight Audit automatically inspects
  add-on templates and the canvas DOM for <h1> tags and enables 1-click "Jump to Widget".

3. Floating Add-on Footer Collision Detection:
For floating widgets (Chat Assistant, Guided Tour, Live Chat FAB, Sticky CTA):
- Always use `var(--footer-offset, 0px)` in your CSS so your widget floats cleanly
  above fixed-bottom footers:
  bottom: calc(24px + var(--footer-offset, 0px));

4. Full-Screen Web Apps & POS Registers (Point-of-Sale):
Add-ons can function as full applications (like Staff Portal or POS Cashier Register):
- Client-side ticket/cart calculation (subtotals, discounts, cash change calculation).
- Thermal receipt print formatting (58mm/80mm):
  @media print {
    body * { visibility: hidden; }
    .pos-receipt-print-area, .pos-receipt-print-area * { visibility: visible; }
    .pos-receipt-print-area { position: absolute; left: 0; top: 0; width: 80mm; }
  }
- Dynamic payment QR code rendering (GCash, Maya, Stripe).

5. CSS Keyframe Animations & Gradients:
Add-on CSS fully supports unscoped @keyframes, multi-stop radial gradients, and
@media (prefers-reduced-motion: reduce) accessibility rules.

================================================================================
🔌 CLIENT JAVASCRIPT (customJs)
================================================================================
- MUST define function onMount(el, props) { ... }
- el = root DOM element of widget instance
- props = resolved key/value properties object
- Optional teardown: el.__wbDestroy = function() { ... }; (cleans up intervals/events)

================================================================================
🎨 CSS GUIDELINES
================================================================================
- Scope all CSS rules under your widget's unique class: .wb-addon-YOUR_ID { ... }
- Use standard AetherBuilder CSS design tokens:
  var(--radius-lg, 12px)
  var(--bg-card, #131b2e)
  var(--text-dim, #94a3b8)
  var(--text-main, #f8fafc)
  var(--border-subtle, rgba(255,255,255,0.08))
